## Package 验证记录

构建命令：

```bash
python -m build --sdist --wheel --outdir DIST_DIR
```

安装命令：

```bash
python -m venv CLEAN_VENV
CLEAN_VENV/bin/python -m pip install DIST_DIR/localize_anything-0.5.0-py3-none-any.whl
CLEAN_VENV/bin/localize --help
```

五命令最小 E2E 应只使用：

```bash
localize scan PROJECT --source-locale en --target-locale ru --source locales/en.json
localize glossary bootstrap PROJECT
localize check PROJECT --target locales/ru.json
localize review PROJECT --target locales/ru.json
localize report PROJECT
```

- `0.5.0` 仍是 0.x；旧平台 CLI、Provider、Workbench、workflow、readiness、signoff
  和 Knowledge Pack 入口不再兼容；
- 兼容 Adapter 必须显式调用，不自动 fallback；
- 项目 build/test、语义翻译、截图和最终产品判断仍属于 Coding Agent/用户；
- Documenso 的 Google Vertex `google.ts` 类型错误是目标应用 baseline 问题；
- 本次不扩大完整 catalog 翻译范围，不修复目标应用外部 blocker。

## 发布前人工命令（本任务不执行）

以下命令只作为人工发布 runbook，必须在最终 clean checkout 和人工批准后执行：

```bash
git status --short
git tag -a v0.5.0 -m "Localize Anything 0.5.0"
git push origin main
git push origin v0.5.0
python -m pip install --upgrade build twine
python -m twine upload dist/*
gh release create v0.5.0 --title "Localize Anything 0.5.0" --notes-file docs/releases/0.5.0-release-notes.md
```

执行顺序必须是：人工 review → clean tag validation → tag → push → package publish →
GitHub Release。任何一步失败都应停止，不移动已有公开 tag。
