# Localize Anything 0.5.1

`0.5.1` is a usability revision from the Hermes clean-environment test against
`mermaid-live-editor`. It keeps the five-command core and does not restore the
old Runtime, add adapters, or change CLI commands.

## Changes

- Clarifies that zero-i18n projects must first create project-native i18n and a
  source resource before `localize scan`.
- Adds explicit `source_target_mapping` output and stronger source/target pair
  validation for `check` and `review`.
- Unifies core severity values: `blocking`, `actionable`,
  `coverage_limitation`, and `informational`.
- Moves auto-cleared independent-review checks into `review_items`; findings now
  count only real review issues.
- Documents minimal canonical Glossary edits for locking a translation and
  preserving a term.
- Adds review-packet field descriptions and a complete JSON quickstart.

## Compatibility

The public CLI command set and arguments are unchanged. JSON review payloads
should use the new severity values and put auto-cleared checks in
`review_items`.
